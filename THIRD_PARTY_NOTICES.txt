* Microsoft Visual C++ Redistributable (v14 family: 2015-2022)

This application requires the Microsoft Visual C++ Runtime to function. CanScan uses a single unified installer to ensure compatibility across all Windows distribution channels:
- Bundled Runtime: The installer redistributes the Microsoft Visual C++ Redistributable (x64) as provided by Microsoft. Redistribution is performed in accordance with Microsoft's licensing terms for Visual Studio. The redistributable is used unmodified solely to enable runtime compatibility for the GraalVM native-image execution environment.
- Winget Compatibility: Although the installer is unified, installation via Winget allows the system to treat the runtime as a formal dependency, ensuring it is correctly registered and updated via official Microsoft channels.
