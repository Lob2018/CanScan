Detailed Description

Defines the filtering strategies for text input fields.

These types determine how characters are sanitized and validated before being committed to the document model.

Member Data Documentation

◆ FREE

fr.softsf.canscan.ui.field.FieldFilterType.FREE

Free-text filtering mode.

Allows all characters to maintain compatibility with the FREE delimited format and strips all line breaks (
, \r) to ensure single-line integrity.

◆ NUMERIC

fr.softsf.canscan.ui.field.FieldFilterType.NUMERIC

Numeric and coordinate filtering mode.

Restricts input to digits (0-9), decimal points (.), and minus signs (-). Also strips line breaks (
, \r) to prevent input corruption in geographic coordinates.

◆ STRICT

fr.softsf.canscan.ui.field.FieldFilterType.STRICT

Strict filtering mode.

Prohibits semicolons (';') to maintain compatibility with MECARD/MEET delimited formats and strips all line breaks (
, \r).
